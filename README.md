# Заказы и отгрузки TRADECOM

Доска заказов (Корея → Владивосток): этапы сделки, документы, календарь.
Сайт — `index.html` (GitHub Pages), данные и файлы — в Supabase, вход — через Google.

- `config.js` — адрес проекта Supabase и публичный ключ (anon). Секретные ключи сюда не кладутся.
- `shim.js` — связь доски с Supabase и окно входа.
- `schema.sql` — таблицы и правила доступа; список разрешённых почт задаётся в Supabase (таблица `allowed`).
